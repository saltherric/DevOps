# CI/CD Lab: Building a CI/CD Pipeline with GitHub Actions

A Node.js web application with a Continuous Integration (CI) pipeline configured via GitHub Actions.

## Tech Stack
- **Node.js**: >=24
- **Package Manager**: Yarn 4
- **Web Framework**: Express 5
- **Testing & Assertions**: Mocha, Chai, Supertest
- **Linter**: ESLint (v9+ flat config)
- **Code Coverage**: c8

## Commands
- `yarn start` - Start the Express server on port 3000 (or `PORT` env var).
- `yarn test` - Run tests using Mocha.
- `yarn lint` - Run ESLint code checks.
- `yarn coverage` - Run Mocha with c8 coverage reporting.
